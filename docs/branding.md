# React Fluid branding

The primary logo is [assets/react-fluid-logo.png](../assets/react-fluid-logo.png).
Use the relative file in README and repository docs so branding does not depend
on an external image host. Its alt text should identify React Fluid, not Slither
or the upstream package.

The new mark keeps the original's rounded RF lettering, cyan/blue palette and
white sticker border. Swept letter shapes, flowing contours and broad highlights
give the fork its own motion-inspired treatment. RF now abbreviates React Fluid.

Keep the square aspect ratio, clear padding and transparent rounded corners.
Do not stretch the logo, add another drop shadow, or crop the white border. Use
the normal text heading “React Fluid” beside or below it where a full name is
needed. The README displays the icon at 200 pixels wide.

## Source and generation

The reference is the [original React Flow RF logo](https://i.imgur.com/I1CRYmc.png)
linked from OutOfBears' README. This project retains upstream attribution and the
[original MIT license](../LICENSE.md).

The replacement was generated with the built-in image-generation tool using that
image as a visual reference, then saved into this repository. The complete prompt
is recorded in [assets/logo-prompt.md](../assets/logo-prompt.md). It is a raster PNG;
no vector master is included. The logo update changes documentation assets only.
